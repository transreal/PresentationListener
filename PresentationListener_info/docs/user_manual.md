# PresentationListener ユーザーマニュアル

## 概要

PresentationListener は、講義・プレゼンテーション中の音声を継続録音し、スライド画像と組み合わせてリアルタイムに AI 解説をノートブックへ書き込むパッケージです。制御はコントロールパレットまたは公開 API 関数から行えます。Web カメラを使わず、音声だけを収録することもできます（後述の「収録モード（画像+音声 / 音声のみ）」を参照）。

発表言語は日本語に限りません。書き起こしは発表された言語のまま保存され、解説は出力言語（`$Language`）で生成されます。発表が出力言語と異なる場合は、発言の訳も併記されます。聴衆からの質問を発表者へ声で伝え、発表者の声の回答を文字で残す **音声質問（Voice Q）** にも対応しています。また、ここまでの発表を要約して別ノートにまとめる **発表のまとめ（📝 まとめ）** も使えます。

パレットには、いま効いている入力デバイス（マイク・カメラ）が常時表示されます。開始前に取り違えを確認できます（後述の「マイク / カメラ表示」を参照）。

---

## パレット（コントロールパネル）

### ShowPalette

パレットウィンドウを表示します。

```mathematica
ShowPalette[]
```

パレットは画面右端に常時表示され、録音の開始・停止・設定変更をワンクリックで操作できます。Palettes メニューの **Presentation Listener** からも起動できます。

**パレット上のボタン・表示一覧**

| ボタン・表示 | 機能 |
|--------|------|
| `▶ Start` | リスナー録音を開始します |
| `■ Stop` | 録音を停止します |
| `Capture` | 現在のスライドを手動キャプチャします |
| `? Question` | 質問ダイアログを開きます（文字による質問） |
| `🎤 Voice Q` | 音声質問ダイアログを開きます。回答待ちの間は `✓ 回答を確定` に変わります |
| `📝 まとめ` | ここまでの発表のまとめを別ノートへ作成します。作成中は `⏳ まとめ中…` に変わります |
| `▶ Process` | セル処理ダイアログを開きます |
| `収録: 画像+音声 / 音声のみ` | 収録モードを切り替えます（「設定」欄の先頭。録音中も可） |
| `マイク: …` / `カメラ: …` | いま効いている入力デバイスを表示します。クリックすると Settings ダイアログが開きます |
| `Settings...` | 詳細設定ダイアログを開きます |
| `Diagnostics` | 診断情報を出力します |

`🎤 Voice Q` の下には、音声質問の進行状況（「音声質問を開始しました。」など）が小さく表示されます。`📝 まとめ` の下にも、まとめの進行状況が小さく表示されます。

### マイク / カメラ表示

パレットの「設定」欄には、収録モードのボタンの下に `マイク: …` と `カメラ: …` の 2 行が表示されます。録音を始める前に、使われる入力デバイスを確認して取り違えを防ぐための表示です。

**表示される内容**

- **停止中**：Settings ダイアログの設定（`cfgDevice` / `cfgVideoDevice`）から解決したデバイスを表示します。設定が `Automatic` のときは、デバイス名の後ろに `(既定)`（マイク）または `(自動)`（カメラ）が付きます。
- **収録中**：実際に開いているデバイスを表示します。カメラは、音声のみへ切り替え中でも保持している映像デバイスを基準にします。

**表示の状態**

| 表示 | 意味 |
|---|---|
| デバイス名（濃い灰色） | デバイスが解決できています。dshow の ID（`@device_pnp_...` など）は、デバイス一覧にあれば表示名に変換されます。一覧に無ければ ID がそのまま表示されます |
| `未検出`（赤） | デバイスが解決できませんでした |
| `なし`（灰色） | カメラが設定されていません（映像デバイスなし） |
| `停止 (音声のみ)`（灰色） | 音声のみ収録のため、カメラ行は使用していません |

行にマウスを載せると、ツールチップにデバイスの ID（取得できない場合は表示文字列）が表示されます。

**解決のタイミング**

デバイスの解決では ffmpeg（`-list_devices`）と PowerShell（既定マイクの取得）を呼び出します。そのため、パレット表示のたびには行いません。解決するのは次の 2 回だけです。

1. `ShowPalette[]` でパレットを開いたとき
2. Settings ダイアログで OK を押したとき

結果は内部に保持され、パレット側はその結果とデバイス一覧のキャッシュだけで名前を表示します。パレット表示中にデバイスを抜き差しした場合は、`ShowPalette[]` を再実行するか、Settings で OK を押すと表示が更新されます。ffmpeg が見つからないときは、デバイス名の代わりに `ffmpeg なし` と表示されます。

## 録音制御

### StartListener

プレゼンテーションリスナーを開始します。

```mathematica
StartListener[]
StartListener[
  "Device"          -> "MacBook Proのマイク",
  "VideoDevice"     -> "FaceTime HD Camera",
  "CaptureInterval" -> 5,
  "SlideThreshold"  -> 0.15
]

(* 音声のみで開始する *)
StartListener["AudioOnly" -> True]
```

| オプション | 型 | 説明 |
|---|---|---|
| `"Device"` | String | 使用するオーディオデバイス名 |
| `"VideoDevice"` | String | スライドキャプチャ用カメラデバイス名 |
| `"CaptureInterval"` | Integer | キャプチャ間隔（秒） |
| `"SlideThreshold"` | Real | スライド変化検出の閾値（0〜1） |
| `"Language"` | String / Automatic | 発表言語（後述の「発表言語と出力言語」を参照） |
| `"AudioOnly"` | True / False / Automatic | `True` で Web カメラを使わず音声のみ収録、`False` で画像+音声。`Automatic`（既定）は現在の `$ListenerAudioOnly` の値を使います |
| `"ChunkDuration"` | Integer | 録音を区切る長さ（秒、既定 60） |
| `"MinParagraphLength"` | Integer | 解説を生成する最小段落長（文字数、既定 80） |

オプションを省略すると、設定ダイアログで保存した値が使用されます。

録音・キャプチャには ffmpeg が必要です。見つからない場合は開始に失敗し、その理由がパレットに表示されます（後述の「ffmpeg の検出」を参照）。

---

### StopListener

録音を停止します。

```mathematica
StopListener[]
```

停止後、録音中に蓄積されたセグメントの最終処理が行われます。停止後に届いた AI の応答は捨てられます。

---

## 収録モード（画像+音声 / 音声のみ）

既定では、音声に加えて Web カメラでスライド画像を収録します（**画像+音声**）。カメラが不要・使えない場合は、音声だけを収録・処理する **音声のみ** モードに切り替えられます。音声のみのときはカメラを開かず、スライド画像のキャプチャや差分判定も行いません。

### $ListenerAudioOnly

```mathematica
$ListenerAudioOnly          (* 既定: False = 画像と音声 *)
$ListenerAudioOnly = True   (* 音声のみ *)
```

`True` なら Web カメラを使わず音声だけを収録・処理します。パレット「設定」の `収録: …` ボタンで切り替えられ、`StartListener` の `"AudioOnly"` オプションで開始時に指定することもできます。収録中に切り替えた場合は、次のキャプチャから反映されます。

### ListenerSetAudioOnly

音声のみ収録 / 画像と音声の収録を切り替えます。収録中でも使えます。

```mathematica
ListenerSetAudioOnly[True]    (* 音声のみにする *)
ListenerSetAudioOnly[False]   (* 画像+音声にする *)
ListenerSetAudioOnly[]        (* 現在の状態を反転 (トグル) *)
```

- 停止中に呼ぶと、`$ListenerAudioOnly` を設定するだけで、`"音声のみ"` または `"画像+音声"` を返します。次回の開始時に反映されます。
- 収録中に `True` で呼ぶと、カメラの使用を止めて音声のみで続行します。
- 収録中に `False` で呼ぶと、映像デバイスを解決し直して画像収録へ戻します。このとき、スライドの差分判定は初期化されます。
- 切り替えると、ノートブックに「収録: 音声のみ」「収録: 画像+音声」といった記録が小さく書き込まれます。画像+音声へ戻そうとして映像デバイスが見つからない場合は、「画像+音声 (映像デバイスが見つからないため音声のみ)」と記録され、音声のみのまま続きます。
- 戻り値は `"音声のみ"` / `"画像+音声"`、収録中に映像デバイスが無いときは `"映像デバイスなし"` です。

### パレットでの切り替え

パレットの「設定」欄の先頭にある `収録: 画像+音声` / `収録: 音声のみ` をクリックするたびに切り替わります（音声のみのときは紫色で表示されます）。`▶ Start` ボタンで開始した場合も、このときの収録モードが使われます。音声のみのときは、`カメラ:` の行に `停止 (音声のみ)` と表示されます。

### 音声のみのときの注意

- `Capture`（`CaptureNow[]`）は使えず、「音声のみ収録中です (パレットの「収録」で画像+音声に切り替え)」と表示されます。
- 音声のみで開始しても、解決した映像デバイスは保持されるため、途中で画像+音声へ戻せます。

## キャプチャ・質問

### CaptureNow

現在のスライド画面を即時キャプチャします。

```mathematica
CaptureNow[]
```

録音中・停止中を問わず使用できます。キャプチャ画像はセッションに記録されます。音声のみ収録中は、キャプチャは行われません。

---

### AskQuestion

現在のスライド・文脈に対して質問を送信し、回答をノートブックに挿入します。

```mathematica
AskQuestion["この定理の証明を詳しく説明してください"]
```

引数なしで呼び出すと入力ダイアログが開きます。

```mathematica
AskQuestion[]
```

回答は固定の日本語ではなく、出力言語（`$Language`）で生成されます。

**関連するスライド画像の選び方**

質問文に `#3` のようなスライド番号が含まれていれば、そのスライドの画像を添えて問い合わせます。番号が無いときは、質問の語と各セクションの発言・解説・訳との重なりで順位を付け、上位 2 つのセクションのスライドを添えます。どのセクションにも合わないときは最後の節のスライドを使います。図の再現などスライドを見ないと答えられない質問に対応するためです。

- 語は、3 文字以上の英数字の語と、ひらがなを含まない 2 文字の語（漢字・カタカナ・数字）です。
- どのセクションにも出る語ほど軽く数えます（IDF）。

**回答待ちの質問**

⚡高速モードでは解説と同じく API を直接呼び出します（claudecode のジョブを通りません）。🔧標準モードでは `ClaudeQueryAsync` を使います。API エラーや無応答（通信・タイムアウト・要求の形の拒否など）のときは、🔧標準で 1 回取り直します。それでも応答が得られない場合は、「API から応答がありませんでした」といったエラー文字列を回答として書かず、エラーとして記録します。前の質問の訳が遅れて届いても、今の質問の読み上げ文は変わりません。

---

## 音声質問（Voice Q）

音声質問は、聴衆からの質問を発表者へ **声で** 伝え、発表者の **声の回答を書き起こして** ノートブックに残す機能です。

### 使い方

1. パレットの `🎤 Voice Q` をクリックし、質問文を入力（または確認）します。
2. パッケージの取り次ぎ役（音声モデル `gpt-live-1`）が、質問を発表者へ読み上げます。
3. 読み上げが終わると、発表者の回答の受付が始まります。パレットのボタンは `✓ 回答を確定` に変わります。
4. 発表者が回答し終えたら `✓ 回答を確定` をクリックします。回答が書き起こされ、質問と回答がノートブックに書き込まれます。

```mathematica
(* 回答の受付を終えて確定する (パレットの ✓ 回答を確定 と同じ) *)
VoiceQuestionFinish[]
```

回答待ちでない状態で呼ぶと、「回答待ちではありません。」と表示されます。

### 動作の詳細

- **質問は原文のまま読まれます。** 取り次ぎ役は、聴衆から発表者への質問を、書かれたとおりの言語と文言で伝えます。質問に自分で答えることはしません。
- **発表者の言語への翻訳。** 発表者の言語の手がかりがある場合、質問はまず発表者の言語へ翻訳されます。手がかりが無い場合は質問をそのまま読み上げます。質問と出力言語が同じ文字種（日本語・韓国語・中国語）のときは、翻訳を省いて待ち時間なしで読み上げます。翻訳は短いため、⚡高速モードでは解説と同じ curl 直接呼び出し、🔧標準モードでは `ClaudeQueryAsync` で行われます。翻訳ジョブが応答なしで終わった場合は、原文のまま読み上げます。
- **回答の翻訳。** 回答の訳が届かない（ジョブが消えた・期限切れ）場合は、訳を付けずに回答を書き込みます。
- **読み上げ以外は話しません。** 待機中はマイクを閉じ、回答中も取り次ぎ役は返事・相づち・お礼・要約・感想を言いません。発表者の回答が読み上げの途中で始まった場合は、取り次ぎ役が話し出したら止められます（発話の割り込みは 3 秒に 1 回まで）。
- **回答の集計。** 読み上げが終わった後の発話だけが回答として扱われます。回答の書き起こしは、途中で履歴が切れないよう逐次集めて保持します。
- **ミュート状態の復元。** 音声質問のために借りたセッションは、終了後に元のミュート状態へ戻されます。

### 必要条件

- OpenAI API キー（`OPENAI_API_KEY`）が登録されていること。
- パレットの **課金API: 許可** が有効であること。音声質問ではノート単位の承認は求めず、パレットの設定で課金の承認を受けます。
- ffmpeg が利用できること。

## 発表のまとめ（ListenerSummary）

ここまでの発表の内容を要約し、別ノートにまとめる機能です。発表が続いている途中でも作成できます。

### 使い方

```mathematica
ListenerSummary[]
```

パレットの `📝 まとめ` をクリックしても同じです。作成中はボタンが `⏳ まとめ中…` に変わります。作成中にもう一度押しても新しい作成は始まらず、状況が表示されるだけです。

### まとめの内容

AI に、現時点までの記録（発言の音声認識・別の AI の解説・訳）を渡して、次の 3 つを作らせます。

| 項目 | 内容 |
|---|---|
| 要約（summary） | ここまでの発表の簡潔なまとめ（3〜6 文）。発表の目的・主な主張・どこまで話が進んだか |
| 鍵になるポイント（key_points） | 発表を理解するうえで鍵になる点（3〜7 個）。一文の要点と、なぜ重要か・どこで効いてくるか（1〜2 文）を添えます |
| 追加情報がないと理解できない点（open_questions） | 記録だけでは理解しきれず、疑問を解いたり質問したりして追加の情報を得ないと理解できない点（0〜6 個）。定義されないまま使われた用語・記号、飛ばされた論証、根拠が示されていない主張、聞き取れない・曖昧な箇所など |

記録は進行中の発表のものとして渡されるため、発表がまだ続いている可能性を踏まえてまとめられます。

### 保存と更新

- まとめノートは 1 回の収録につき 1 冊です。押すたびに経過時間を添えた内容が、同じファイルへ上書き保存されます。
- 保存先の候補には、設定済みのフォルダに加えて「書類フォルダ」と「前に保存したフォルダ」も使われます。どれで保存したかはノートに書かれます。
- 保存先が解決できなかった場合の警告は、1 回の収録につき 1 度だけ表示されます。保存は次の節でまた試します。

### 処理モード

⚡高速モード（課金API 許可）では解説と同じく API を直接呼び出します。🔧標準モードでは `ClaudeQueryAsync` を使います。API エラー・無応答のときは 🔧標準で 1 回取り直します。

## 発表言語と出力言語

| 項目 | 役割 |
|---|---|
| 出力言語（`$Language`） | 解説・質問への回答・タイトルを書く言語 |
| 発表言語（`"Language"` オプション） | 音声認識（Whisper）に伝える発表の言語 |

- **書き起こしは言語を変えません。** 音声認識の誤り修正（同音異義語・聞き誤り・明らかな誤字の修正）は、発表された言語のまま行われます。文構造・語順・句読点は変えず、修正不要ならそのまま返します。翻訳は解説の生成時に行われます。
- **翻訳の併記。** 発言が出力言語と異なるときは、発言の訳も解説に併記されます。出力言語と同じ文字種のときは訳さずにそのまま出力します。原文が先に表示され、訳は届き次第続けて書き込まれます。訳が遅れて届いた場合も、続けて書き込まれます。
- **`"Language"` の指定。** 言語名（`"Japanese"`、`"English"`、`"Chinese"`、`"ChineseSimplified"`、`"ChineseTraditional"`、`"Arabic"`、`"Hindi"`、`"Indonesian"`、`"Vietnamese"`、`"Dutch"`、`"Polish"`、`"Turkish"` など）または言語コード（`"ja"`、`"zh"` など）を指定できます。`Automatic` にすると `language` を付けず、Whisper が自動判定します。
- **タイトル。** 解説の 1 行目に付くタイトルは、短い名詞句です（日本語なら 10〜25 文字）。英語など ASCII のタイトルは 1 文字あたりの情報量が少ないため、長めに残されます。単語の途中では切りません。

## 応答の見張りと取り直し

🔧標準モードの AI 問い合わせ（解説・質問への回答・翻訳・まとめなど）は `ClaudeQueryAsync` で行われ、応答は callback で受け取ります。応答が届かないまま止まらないよう、次の見張りがあります。

- 一定時間応答が無い場合は、期限切れとして扱い、**🔧標準で 1 回取り直します**。API エラー・無応答（通信・タイムアウト・要求の形を拒否された等）も同様です。
- 取り直しても応答が無い場合は諦めます。解説・回答としてエラー文字列を書くことはしません（タイトルに拾われて保存名になってしまうのを避けるためです）。
- 音声認識の誤り修正を諦めたときは、原文を書き起こしとして残します。段落がたまっていれば、解説なしの節として書き込みます。
- 諦めた後・停止後に届いた応答は捨てられます。解説や回答が二重に書かれることはありません。

## ffmpeg の検出

ffmpeg の実行ファイルは PATH だけに頼らず、次の順で探されます。winget などで入れた直後で PATH に反映されていない場合でも、再起動せずに使えます。

1. `$FFmpegPath` が文字列で設定されていればそのパス
2. PATH 上の `ffmpeg`
3. 既知のインストール先
   - `C:\ffmpeg\bin\ffmpeg.exe`
   - `C:\ProgramData\chocolatey\bin\ffmpeg.exe`
   - `C:\Program Files\ffmpeg\bin\ffmpeg.exe`
   - scoop の shims（`%USERPROFILE%\scoop\shims\ffmpeg.exe`）
   - WinGet のパッケージ（`%LOCALAPPDATA%\Microsoft\WinGet\Packages` 以下の `*FFmpeg*`）

検出結果はキャッシュされます。見つからなかった場合は 10 秒ごとに探し直します。

見つからない場合は、パレットに理由が表示されます。パレットのマイク / カメラ表示には `ffmpeg なし` と表示されます。設定ダイアログ（Settings...）でデバイス一覧が空のときも、「ffmpeg (…) が dshow デバイスを 1 つも返しませんでした。」のように理由が表示されます。ffmpeg は dshow デバイス名を UTF-8 で出力しますが、これを 1 バイト 1 文字で受けて文字化けする問題は自動で補正されます（例：「マイク」）。

内部状態の診断情報を文字列で返します。トラブルシューティングに使用します。

あわせて、設定されているデバイス（`cfgDevice` / `cfgVideoDevice`）と、パレットに表示しているマイク / カメラ名（`paletteDevices`）も出力されます。パレットの表示が想定と異なるときの切り分けに使えます。待機中の質問（`asks`）の数も出力されます。

## パレット設定の詳細

パレット上のトグルボタンで、以下の設定をセッション中に切り替えられます。

### 収録（画像+音声 / 音声のみ）

「設定」欄の先頭のボタンです。クリックするたびに `収録: 画像+音声` と `収録: 音声のみ` が切り替わります。録音中でも切り替えられ、`$ListenerAudioOnly` と連動します。詳細は「収録モード（画像+音声 / 音声のみ）」を参照してください。

---

### マイク / カメラ表示

収録ボタンの下にある `マイク: …` / `カメラ: …` の 2 行です。停止中は設定から解決したデバイス、収録中は実際に開いているデバイスを表示します。クリックすると Settings ダイアログが開くので、デバイスを変更して OK を押すと表示が更新されます。詳細は「パレット」の「マイク / カメラ表示」を参照してください。

---

### 処理モード（⚡ / 🔧）

| 表示 | モード | 説明 |
|---|---|---|
| ⚡ 高速 | Fast Mode | Anthropic API を直接呼び出し、低遅延で解説を生成します。質問への回答・まとめ・翻訳も同様に API を直接呼びます |
| 🔧 標準 | Standard Mode | [claudecode](https://github.com/transreal/claudecode) CLI 経由で安定動作します |

高速モードは **課金API: 許可** が有効なときのみ選択できます。

---

### モデル選択

パレットの「モデル」ボタンをクリックするたびに切り替わります。

| 表示 | モデル |
|---|---|
| Default | 自動選択 |
| Opus | Claude Opus（高品質） |
| Sonnet | Claude Sonnet（バランス） |

---

### エフォートレベル

Opus モード時のみ有効です。「エフォート」ボタンで切り替えます。

| 表示 | レベル | 説明 |
|---|---|---|
| Low | 低 | 短い解説、高速 |
| Med | 中 | 標準（デフォルト） |
| High | 高 | 詳細な解説 |
| Max | 最大 | 最も詳細、低速 |

---

### 課金API 許可/禁止

**課金API: 許可** にすると Anthropic API への直接アクセスが有効になります。API キーが必要です。**禁止** にすると高速モードは自動的に無効になります。音声質問（Voice Q）もこの設定で課金の承認を受けます。

## 典型的なワークフロー

### 1. パレットを使った基本操作

```mathematica
(* パッケージをロードしてパレットを表示 *)
Needs["PresentationListener`"]
ShowPalette[]

(* パレットの ▶ Start をクリックして録音開始 *)
(* 講義終了後、■ Stop をクリック *)
```

開始前に、パレットの `マイク:` / `カメラ:` の表示で、使われるデバイスが意図したものか確認してください。違う場合は、その行（または `Settings...`）から設定を変更します。

### 2. コードからの操作

```mathematica
Needs["PresentationListener`"]

(* 録音開始 *)
StartListener[
  "Device" -> "MacBook Proのマイク",
  "CaptureInterval" -> 10
]

(* 途中でスライドを手動キャプチャ *)
CaptureNow[]

(* 質問を追加 *)
AskQuestion["先生が言及した定理の名前は何ですか？"]

(* 録音停止 *)
StopListener[]

(* セッションをエクスポート *)
ExportSession["lecture_20260610.json"]
```

### 3. 英語など日本語以外の発表

```mathematica
Needs["PresentationListener`"]

(* 発表言語を明示する *)
StartListener["Language" -> "English"]

(* 言語を指定せず Whisper の自動判定に任せる *)
StartListener["Language" -> Automatic]
```

書き起こしは英語のまま保存され、解説は出力言語で書き込まれます。発言の訳も併記されます。

### 4. 聴衆の質問を発表者へ声で伝える

1. 録音中に、パレットの `🎤 Voice Q` をクリックして質問を入力します。
2. 取り次ぎ役が質問を読み上げます。
3. 発表者が声で答えます。
4. `✓ 回答を確定` をクリックします。質問と回答の書き起こしがノートブックに残ります。

### 5. カメラを使わず音声だけを収録する

```mathematica
Needs["PresentationListener`"]

(* 音声のみで開始 *)
StartListener["AudioOnly" -> True]

(* 途中で画像+音声へ戻す *)
ListenerSetAudioOnly[False]

(* 再び音声のみにする / 切り替え (トグル) *)
ListenerSetAudioOnly[True]
ListenerSetAudioOnly[]
```

パレットの `収録: …` ボタンでも同じ切り替えができます。

### 6. SourceVault との連携

[SourceVault](https://github.com/transreal/SourceVault) がインストールされている場合、セッション終了時にノートが自動的に SourceVault へ保存されます。設定は Settings ダイアログで管理します。

### 7. 発表の途中でまとめを作る

```mathematica
Needs["PresentationListener`"]
StartListener[]

(* 発表の途中で、ここまでのまとめを別ノートへ *)
ListenerSummary[]
```

パレットの `📝 まとめ` でも同じです。もう一度押すと、同じまとめノートが最新の内容で上書きされます。

## 注意事項

- 録音開始前に Mathematica がマイクへのアクセス許可を持っていることを確認してください。
- ffmpeg が見つからないと録音を開始できません。インストール直後でも `$FFmpegPath` を設定するか、既知のインストール先に置けば検出されます。
- パレットの `マイク:` / `カメラ:` 表示は、`ShowPalette[]` を開いたときと Settings の OK のときにだけ更新されます。デバイスを抜き差ししたあとは、`ShowPalette[]` を再実行してください。
- `"CaptureInterval"` を短く設定するとシステム負荷が上昇します。初期値は 5〜10 秒を推奨します。
- 音声のみ収録中は `Capture` が使えません。スライド画像が必要なときは、`収録` ボタンまたは `ListenerSetAudioOnly[False]` で画像+音声へ戻してください。
- 高速モード（⚡）を使用するには、API キーが正しく設定されている必要があります。詳細は setup.md を参照してください。
- 音声質問（Voice Q）には、OpenAI API キーとパレットの「課金API: 許可」が必要です。
- 発表のまとめ（`ListenerSummary[]`）は、ノートブックの内容ではなく収録した記録をもとに作られます。保存先が解決できない場合は、保存先フォルダの設定を確認してください。
- `DiagState[]` の出力はサポートへの問い合わせ時に添付してください。
